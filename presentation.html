Financial Mathematics

Portfolio Valuation & Accounting Rigor

Enterprise-grade precision accounting preventing IEEE 754 floating point errors

W WealthEdge

Weighted Average Cost Basis (BUY)

AvgPrice = (Q_prev × P_prev + Q_buy × P_buy) / (Q_prev + Q_buy)

Recalculated dynamically upon every BUY execution. Seamlessly accounts for dollar-cost averaging and staggered accumulation.

Realized vs Unrealized P&L (SELL)

Realized_PnL = (P_sell - AvgPrice) × Q_sell
Unrealized_PnL = (P_cmp - AvgPrice) × Q_active

Locked into immutable transaction ledger on trade execution. Prevents users from selling more shares than actively held.

Persistence

Zero-friction deployment across Cloud PostgreSQL, Local MySQL, and Embedded H2

Render production database parsed dynamically from DATABASE_URL environment variables using HikariCP connection pooling.
